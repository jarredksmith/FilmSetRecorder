# FilmSet Recorder 0.5.0 — Production Console UI

This release is a visual and workflow redesign intended to make the recorder feel like a dedicated production-sound application rather than a prototype.

## Desktop

- New low-chrome production-console layout.
- Slate, ISO meters, clock and transport remain visible during normal operation.
- Compact project/format/health bar.
- Full-width slate strip with live next-filename preview.
- Meter-first central workspace with dBFS reference scale.
- Inspector architecture for Audio, Notes, Takes, Remote and System.
- Take table restyled as a professional media browser.
- Diagnostics moved away from the primary recording surface.
- More restrained typography, borders, spacing, status indicators and color use.
- Large Record/Stop controls retained without oversized dashboard cards.

## Web remote

- Restyled to match the desktop design language.
- Reduced decorative cards, gradients, shadows, oversized rounding and icon-heavy labels.
- Clearer slate, meter, transport and take-history hierarchy.
- Existing QR pairing, phone audition and recorder playback preserved.

## Packaging

- Windows and macOS workflows remain supported.
- Installer/artifact names updated to 0.5.0.
