# FilmSet Recorder roadmap

## 0.2 - Recorder foundation

- Stable multichannel capture path
- Modern UI
- Pre-roll
- Partial-file recovery
- Sound reports
- Remote controller API
- Diagnostics and stress-test workflow

## 0.3 - Production metadata

- BWF `bext`
- iXML
- time-of-day time reference
- richer track metadata
- roll/day organization and take-history browser
- edit previous take notes and circle status in-app

## 0.4 - Production monitoring

- configurable monitor mix
- output routing
- slate/talkback routing
- optional mix track
- safety tracks
- per-track polarity and digital trim where technically appropriate

## 0.5 - Timecode

- LTC input decode
- timecode display
- jam / drift diagnostics
- frame-rate-aware timestamps
- external controller timecode status

## 0.6 - Field hardening

- automated multi-hour soak tests
- device disconnect/reconnect handling
- secondary-drive mirrored recording
- enhanced file-integrity verification
- signed Windows installer
- signed/notarized macOS app

## Later

- take browser and playback cueing
- waveform overview
- PDF daily sound report
- MIDI / HID controller support
- richer ESP32 handheld UI with meter page, slate page, battery indication, and setup screen
